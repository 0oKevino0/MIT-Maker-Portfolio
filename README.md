## Source provenance and access

Laboratory repositories are linked directly without copying their code here or changing their authorship. The research page distinguishes the 2025 World Neurosurgery study from related laboratory work described in a separate 2026 manuscript. Links do not assign authorship of every upstream file to me.

The AI CAD Tutor snapshot preserves the reviewed source bytes. Its original metadata declares Proprietary; public inspection does not grant a new open-source license. Its [license notes](projects/01-ai-cad-tutor/LICENSE_STATUS.txt) and [dependency notices](projects/01-ai-cad-tutor/DEPENDENCIES_AND_LICENSES.json) remain with the project. Each external repository retains its own terms.

Model weights, course materials, private configuration, laboratory data, and original development history are excluded. The [review manifest](REVIEW_MANIFEST.json) records repository-relative paths and SHA-256 hashes. The [portfolio code guide](PORTFOLIO_CODE_GUIDE.md) remains available as a compatible navigation page.
